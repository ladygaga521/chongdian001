1. 支付模式

选「自动识别」后，微信扫码 → JSAPI，支付宝扫码 → 手机网站支付
真实支付的回调地址必须是 HTTPS + ICP 备案域名，如 https://pay.example.com

2. 微信 JSAPI 支付

需要：服务号 AppID（已认证并开通 JSAPI 支付 + 网页授权域名）、商户号、API 证书

请勿上传到公开仓库；存储在本机数据库中

3. 支付宝手机网站支付

需要：开放平台网页/移动应用 AppID、已开通「手机网站支付」、RSA2 密钥对

4. 彩虹易支付

聚合支付网关，一套参数同时收支付宝和微信，无需单独申请微信/支付宝商户。 需要：易支付商户 ID（pid）、商户密钥（key）、网关地址

易支付站点首页地址，代码会自动拼 /submit.php 和 /api.php
点一下会请求易支付网关，验证商户 ID 和密钥是否正确

上线前请确认

  1. 域名已 HTTPS 备案，且证书有效（微信/支付宝强制要求）。
  2. 微信：服务号已完成认证 → 开通「JSAPI 支付」→ 配置「网页授权域名」和「支付目录」为本系统域名。
  3. 支付宝：应用已开通「手机网站支付」→ 设置「应用网关地址」「授权回调地址」为本系统地址。
  4. 彩虹易支付：把商户 ID / 密钥填好，异步通知地址填 - 并确保公网可达。
  5. 回调地址默认为 - 和 -，需能被公网访问。
  6. 本地调试只能用「模拟支付」；真实支付必须部署到备案域名下。
